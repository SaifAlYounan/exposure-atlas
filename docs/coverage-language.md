# Coverage language (FND-005 — draft)

- Every percentage names a denominator, boundary version and as-of date.
- Tracker overlap is "coverage against <tracker>", never completeness.
- A tracker used for discovery is not an independent recall denominator.
- `no_match_is_not_absence`: citation absence never implies no
  proceeding exists.
- `none_known` requires a successful versioned SearchedScope.
- Confidential/inaccessible material is a named gap, never covered.
